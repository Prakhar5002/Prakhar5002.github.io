How I build

Four things I won't compromise on

01

Payments that never double-charge

Every money path is idempotent and survives the user leaving the app mid-payment.

Idempotency keys, exactly-once UPI across app-switch round-trips, hold-release watchdog — Workctrl.

02

Secure by default

Security lands in the app before the audit asks for it.

SSL public-key pinning, device-integrity gate, VAPT hardening — Workctrl.

03

Fast and cheap at scale

Real-time should not mean a runaway bill.

80–90% fewer Firebase reads (measured) after a Kafka → Firebase RTDB migration — Meeting Room Tablet.

04

Ship without a release

Business rules live on the server, so the app keeps up without store reviews.

Server-driven workflow engine; the client renders what the server permits — SW Tickets.
